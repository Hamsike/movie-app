# 🎬 MovieApp

Приложение для просмотра и поиска фильмов с использованием API Кинопоиска.

## 🚀 Функциональность

- 📱 Просмотр популярных фильмов с бесконечной прокруткой
- 🔍 Поиск фильмов с фильтрацией по году, жанру и рейтингу
- ⭐ Добавление фильмов в избранное (сохраняется в localStorage)
- 🔄 Сравнение фильмов
- 📄 Детальная страница фильма
- 🎨 Тёмная тема
- 📱 Адаптивный дизайн

## 🛠️ Технологии

- **React 18** - библиотека для пользовательских интерфейсов
- **TypeScript** - типизация
- **Redux Toolkit + Redux Persist** - управление состоянием и сохранение избранного
- **React Query** - кеширование API запросов
- **React Router v6** - навигация
- **Axios** - HTTP запросы
- **CSS Modules** - стилизация
